国家覆盖级别（Coverage Level）

国家选择器覆盖 ISO 3166-1 全部 249 个国家 / 地区。每个国家按数据完备程度分为三级：

  • localized-full（22 个热门国家）：本地化地址、行政区 / 城市、人名、电话、邮编、货币 / 时区完整，并按国家匹配官方 Sandbox 支付资料；
  • localized-address：地址与人物资料完整本地化，支付使用 Generic Sandbox；
  • generic-safe（其余国家 / 地区）：真实国家 / 首都 / 主要城市数据 + 通用安全生成规则；无邮编规则时邮编字段不显示，不伪造行政层级或邮编。

地图说明

地图仅展示城市 / 行政区 / 国家中心坐标（精度标注为 city-center / region-center / country-center）。生成的合成街道与门牌不做地理编码，也不会把姓名、电话、邮箱、支付资料发送给地图服务。地图瓦片 © OpenStreetMap contributors。

数据边界

  • 国家、行政区、城市为公开地名数据；
  • 街道、门牌、姓名、电话、邮箱、公司等为合成测试数据；
  • 邮编与地区规则关联，无法可靠映射时生成格式合规的测试值；
  • 支付卡号仅来自 Provider 官方公开 Sandbox 测试卡，绝不随机生成；
  • “格式合规”不代表地址真实存在或可投递。
