卡组织规则来源（Card Brand Rule Registry）

规则文件与核验记录保存在仓库的 data/card-brands/ 目录，source-manifest.json 记录来源 URL、核验日期与规则版本。规则版本：2026.09.04。

规则只描述“号码长什么样”，不包含任何真实发卡行 BIN 数据。生成器在最后一位主动选择与正确校验位不同的数字，所有输出都无法通过 Luhn 校验；这一点由单元测试逐卡组织抽样验证。不同国家通过 cardBrandWeights 控制卡组织出现权重（例如中国以 UnionPay 为主、日本包含 JCB、美国包含 Discover）。

国家覆盖级别（Coverage Level）

国家选择器覆盖 ISO 3166-1 全部 249 个国家 / 地区。每个国家按数据完备程度分为三级：

  • localized-full（22 个国家 / 地区）：本地化地址、行政区 / 城市、人名、电话、邮编、货币 / 时区完整，并配置本国卡组织权重；
  • localized-address：地址与人物资料完整本地化，卡组织使用通用权重；
  • generic-safe（其余国家 / 地区）：真实国家 / 首都 / 主要城市数据 + 通用安全生成规则；无邮编规则时不显示邮编字段，不伪造行政层级或邮编。

界面语言

界面支持 16 种语言（简体中文、繁體中文、English、日本語、한국어、Deutsch、Français、Español、Português、Italiano、Русский、العربية、हिन्दी、Bahasa Indonesia、ไทย、Tiếng Việt）。界面语言与“资料本地化”分开管理：无论界面用哪种语言，本地地址与本地姓名始终按所选国家的本地语言输出。

地图说明

地图仅展示城市 / 行政区 / 国家中心坐标（精度标注为城市中心 / 区域中心 / 国家中心）。生成的合成街道与门牌不做地理编码，也不会把姓名、电话、邮箱、银行卡资料发送给地图服务。地图瓦片 © OpenStreetMap contributors，瓦片服务可在 MAP_CONFIG 中替换。

数据边界

  • 国家、行政区、城市为公开地名数据；
  • 街道、门牌、姓名、电话、邮箱、公司、账号等为随机合成数据；
  • 邮编优先与地区关联，无法可靠映射时按该国格式规则生成，不声称可真实投递；
  • 邮箱使用主流服务商域名形式，但不验证账号存在性、不发信；
  • 银行卡只按公开编号结构生成外观数据，全部 Luhn-invalid；
  • 不生成身份证、护照、社保号、银行账户、IBAN 等敏感字段；
  • “格式合规”不代表地址真实存在或可投递。
