# 小产品实验室 · 全球地址生成器

纯前端静态站：真实地名 + 合成测试身份资料（人物 / 地址 / 联系方式 / Sandbox 支付测试卡 / 工作与账号资料），浏览器本地生成，不上传任何数据。

- 打开即生成，选择即更新，全部字段直出
- 22 个国家 / 地区，顶部常用 + 全部国家面板，左侧城市导航
- Seed 可复现；批量 5–500 条；CSV / JSON / JSONL / TXT 导出
- 支付字段仅来自 Provider 官方公开 Sandbox 测试卡，绝不随机生成卡号
- 无构建、无后端、无第三方 API、无 Math.random

上线地址：addressgen.tinylabpro.com（Cloudflare Pages Git 集成）
